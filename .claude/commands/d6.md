description: D6: caregiver dashboard and settings panel via 21st.dev (with F4 and F6)
---

Use the 21st.dev Magic MCP (twentyfirst) component builder to generate two components:

1. A calm caregiver dashboard for a child's communication app: a header with the child's name and today's date, a timeline list of sentences spoken today with times, a "most said today" card with counts, and a card comparing predicted phrases now versus at 12:15. Light theme, generous whitespace, no charts.
2. A settings slide over panel with three large toggles (Buttons, Touch pad, Voice switch), each with a one line description, and a close button. Accessible labels and focus states.

Then adapt both into our app. Rewrite them as React + CSS modules using only the variables in src/styles/tokens.css; do not add Tailwind or shadcn as dependencies. Wire the dashboard to GET /api/aac/patients/{id}/events and /api/predict as F6 describes, and the settings panel to the input settings from F4. Use the fullstack-engineer skill.

Done when: both screens use the same fonts and colors as the board and don't look pasted in from another app.
