Read CLAUDE.md. Make the Speak button in the sentence strip work.

- On press: join the strip labels into a sentence, POST /api/speak, play the returned audio_url with an HTML Audio element, then POST /api/log with the text and current ISO time.
- Disable Speak and show a spinner while waiting. On error, show a short red banner for 3 seconds and keep the sentence.
- After speaking, clear the strip.
- Put API calls in src/api.ts using relative URLs (the Vite proxy handles the backend).

Done when: building a sentence and pressing Speak plays it from the laptop speaker.
